This repository contains the complete laboratory work for the **Client-Side Technologies** track at ITI. The journey started with building semantic, responsive layouts and culminated in architecting complex, event-driven JavaScript systems and custom libraries.

---

## 🗺️ Learning Roadmap

### 🎨 Phase 1: Modern Web Layouts
* **Semantics:** Mastering HTML5 structural tags for SEO and accessibility.
* **Layout Engines:** Advanced responsive design using **CSS Flexbox** and **CSS Grid**.
* **Visuals:** CSS transformations, transitions, and custom animations.

### 🧠 Phase 2: JavaScript Logic & Data
* **Foundations:** Control flow, loops, and mathematical logic.
* **Pattern Matching:** Deep dive into **Regular Expressions (Regex)** for data validation and string parsing.
* **BOM:** Interacting with the **Browser Object Model** (Windows, Location, Navigation, and Timers).

### 🎭 Phase 3: Interactive Systems & State
* **The DOM:** Dynamic element manipulation, state synchronization, and building interactive UI (e.g., Memory Game).
* **Event Architecture:** Custom events, event propagation (Bubbling/Capturing), and keyboard hotkey implementation.
* **Persistence:** Managing user state across sessions using a custom-built **Cookie Library**.
* **Reliability:** Implementing strict **Exception Handling** and defensive programming.

## 🚀 Key Project Highlights

### 🧮 The Regex Math Parser (Day 07)
A complex arithmetic calculator that respects the order of operations (MDAS) using manual string parsing and Regular Expressions, avoiding the use of `eval()` for enhanced security.

### 🍪 Modular Cookie Library (Day 08)
An abstracted JavaScript library that simplifies browser storage through `get`, `set`, and `delete` methods, featuring built-in type validation and persistence management.

### 🃏 State-Based Memory Game (Day 06)
A game built purely with Vanilla JS that handles user selection states, match-checking logic, and dynamic DOM rendering.
